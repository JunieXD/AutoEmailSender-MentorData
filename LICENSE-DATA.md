## Attribution

When sharing or adapting the community data, give attribution in a reasonable form, retain a link to the license, and indicate whether changes were made. A recommended attribution is:

> AutoEmailSender MentorData contributors, “AutoEmailSender MentorData”, dataset version `<version>`, <https://github.com/JunieXD/AutoEmailSender-MentorData>, licensed under CC BY 4.0. Changes were made: `<yes/no>`.

Attribution may be provided once for the dataset or application using it; it does not need to be repeated beside every mentor. Published records retain contributor and official-source provenance for auditability.
